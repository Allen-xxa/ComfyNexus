## 3. 用例详情

### TC-SEC-001 API Key 掩码规则边界

| 字段 | 内容 |
|---|---|
| 优先级 | P0 |
| 设计方法 | 边界值 + 等价类 |
| 前置条件 | 可调用 `mask_api_key`（单测或桥接口） |
| 测试数据 | 空串；`abc`（3）；`abcd123`（7）；`abcd1234`（8）；`sk-test-1234567890abcdef`（24） |
| 操作步骤 | 1. 逐个输入<br>2. 记录输出<br>3. 确认不包含完整原文 |
| 预期结果 | 1. 空串与长度 < 8 返回 `***`<br>2. 长度 8 返回前 4 + `***` + 后 4<br>3. 长 Key 只暴露前 4 与后 4，中间全部掩码<br>4. 任何情况下不返回完整 Key |
| 可自动化程度 | 可自动化 |
| 关联风险 | — |
