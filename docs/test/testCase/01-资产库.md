# 01 资产库（Gallery）测试用例

## 1. 模块信息与前置

| 项 | 内容 |
|---|---|
| 页面入口 | 侧边栏「资产库」，路由 `/gallery` |
| 前端核心 | `source-code/frontend/src/pages/AssetLibraryPage.tsx`、`stores/useAssetStore.ts`、`components/asset/` |
| 后端核心 | `source-code/backend/src/gallery/{scanner,controller,storage,models}.py`、`bridge/api.py` |
| 元数据 | `source-code/data/gallery/assets.json`（全量 JSON 读写，非 SQLite） |
| 分类 | 真实文件夹：`<libraryPath>/<分类名>/` |
| 媒体路由 | `/gallery/thumbnail/<id>`、`/gallery/asset/<id>`（回环 Flask） |
| 公共前置 | 应用已启动；已准备临时库目录 `%TEMP%\cn-gallery-<随机>`；测试结束删除，不使用真实资产库 |

测试数据统一约定：图片 `a.png`（含 workflow）、`b.jpg`、`c.webp`；视频 `v.mp4`、`w.webm`；异常样本 `bad.jpg`（0 字节）、`note.txt`（不支持）、超长文件名 PNG；所有文件名至少一份含中文/空格。
