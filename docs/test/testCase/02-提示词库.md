# 02 提示词库（Prompt）测试用例

## 1. 模块信息与前置

| 项 | 内容 |
|---|---|
| 页面入口 | 侧边栏「提示词库」，路由 `/prompt`（以实际路由为准） |
| 前端核心 | `source-code/frontend/src/pages/PromptManagePage.tsx`、`stores/usePromptStore.ts`、`components/prompt/` |
| 后端核心 | `source-code/backend/src/core/prompt_library/{models,service}.py`、`bridge/controllers/prompt_library_controller.py` |
| 存储 | 数据目录下 `prompts/*.json`、分类与元数据 JSON（带 `DATA_VERSION`） |
| 校验上限 | 名称 ≤ 100、正向 ≤ 10000、反向 ≤ 10000、备注 ≤ 500、标签 ≤ 10 个且每个 ≤ 50 |
| 公共前置 | 应用已启动；已备份 `source-code/data/` 下提示词数据；使用测试分类，不污染真实提示词 |
