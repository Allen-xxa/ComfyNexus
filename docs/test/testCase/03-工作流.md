# 03 工作流（Workflow）测试用例

## 1. 模块信息与前置

| 项 | 内容 |
|---|---|
| 页面入口 | 侧边栏「工作流」，路由 `/workflow`（以实际路由为准） |
| 前端核心 | `source-code/frontend/src/pages/WorkflowManagePage.tsx`、`stores/useWorkflowStore.ts`、`api/workflow.ts`、`components/workflow/` |
| 后端核心 | `source-code/backend/src/core/workflow/{parser,models}.py`、`bridge/controllers/workflow_controller.py` |
| 存储 | 工作流 JSON + 同目录 `metadata.json`；文件夹为虚拟目录 `folder:<relative_path>` |
| 导入格式 | 仅 `.json`，要求顶层为对象且 `nodes` 为数组（ComfyUI UI 格式） |
| 公共前置 | 应用已启动；准备 ① 含 `nodes/links` 的 UI 格式 JSON；② 仅含 `class_type` 的 API 格式 JSON；③ 非法 JSON；④ 重名文件 |
